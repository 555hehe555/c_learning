
# C Learning

A small personal project for learning the C programming language.

This repository contains various experiments, exercises, and small programs written while learning C.

## Projects

- Calculator
- Mini Statistics
- Utility Tools

## Build

The project uses CMake.

```bash
cmake -S . -B build
cmake --build build
```

## About

This is a personal learning project. The code may change, improve, or break as I explore the language and experiment with different programming concepts.
